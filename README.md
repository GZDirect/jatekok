# Játékok

Saját szórakozásra készült böngészős játékok. Mind telepítés nélkül fut, a legtöbb telefonra készült.

**Játékválasztó:** https://gzdirect.github.io/jatekok/

| Játék | Leírás | Mappa |
|---|---|---|
| [Pihe odúja](https://gzdirect.github.io/jatekok/pihe/) | Tamagocsi négy forgatható 3D diorámában (őszi erdő, havas tó, dzsungel, sziget). Kert, horgászat, bújócska, szavak tanítása. | [`pihe/`](pihe/) |
| [Pip terráriuma](https://gzdirect.github.io/jatekok/pip-terrarium/) | Gondozós 3D játék egy pici ugrópókkal. Magyarul és angolul. | [`pip-terrarium/`](pip-terrarium/) |
| [Árnyékerdő](https://gzdirect.github.io/jatekok/arnyekerdo/) | Belső nézetes lopakodó túlélés egy éjszakai erdőben (prototípus). | [`arnyekerdo/`](arnyekerdo/) |

Minden játék a saját mappájában van, egyetlen `index.html` fájlként.
