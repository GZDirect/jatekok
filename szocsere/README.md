# Szócsere

**Játék:** https://gzdirect.github.io/jatekok/szocsere/

Magyar szójáték. Két szót kell kitalálni a meghatározásuk alapján. A két szót egy jelölt pontnál kettévágjuk, és felcseréljük a végüket, így két új szó születik.

Példa: KÉZ|KRÉM + ARC|MOSÓ → KÉZMOSÓ + ARCKRÉM

## Játék
- 5 kör, mindegyikben 5 csere (összesen 25 feladvány).
- A fehér kockákba kell beírni a két szót, a sárga megfejtés-sor magától töltődik.
- Segítség: „Mutasd az 1. szót”, „Mutasd a 2. szót”, „Feladom”.
- A kör végén az eredmény szövegként kimásolható (🟩 segítség nélkül, 🟨 segítséggel, ⬛ feladva).
- A haladás a böngészőben tárolódik, újranyitáskor folytatható.

## Futtatás
Egyetlen önálló fájl: `index.html`. Böngészőben megnyitva azonnal játszható, internet nem kell hozzá. GitHub Pages-en a mappa linkjén érhető el.

## Háttér
Az ötlet egy lejárt magyar szabadalmi bejelentésből indult (P0301084, „Eljárás kis helyigényű szöveges rejtvények készítésére”, oltalma 2005-ben megszűnt). A játékmenet, a feladványok és a program saját fejlesztés.
