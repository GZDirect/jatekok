# Térbeli amőba

**Játék:** https://gzdirect.github.io/jatekok/terbeli-amoba/

Amőba (ötöt egy sorba) egy kocka felszínén, a gép ellen. A vízszintes és függőleges sorok átfordulhatnak a kocka élein, így egy sor két-három lapon is áthaladhat. Az átlós sorok egy lapon belül maradnak.

## Játék
- Három kockaméret: 5×5, 6×6 és 7×7 mező lapként.
- Az nyer, aki előbb kirak öt jelet egy sorban.
- Ha a kocka betelik és senkinek nincs ötöse, a több négyes sort kirakó játékos nyer.
- A kocka egérrel vagy ujjal húzva, illetve a nyilakkal forgatható.

## Futtatás
Egyetlen önálló fájl: `index.html`. Böngészőben megnyitva azonnal játszható, internet nem kell hozzá. GitHub Pages-en a mappa linkjén érhető el.

## Háttér
Az ötlet egy lejárt magyar szabadalmi bejelentésből indult (P0201051, kocka felszínén játszott amőba). A méretek, a döntetlen-szabály, a gépi ellenfél és a program saját fejlesztés.
