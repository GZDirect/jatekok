# AFTERCORE

**Prototípus.** Mom's Couch Studios · Föld, 2046 · Godot 4

Egy felújított fúrógéppel a 2039-es Nagy Törés után megrongált föld alá indulsz: ásol, nyersanyagot gyűjtesz, visszatérsz a saját járatodon, fejlesztesz, és lassan kiderül, mi rezeg a mélyben.

**Játék:** https://gzdirect.github.io/jatekok/aftercore/

Asztali gépen, billentyűzettel játszható. Az első betöltés pár másodpercig tart (kb. 40 MB).

| Művelet | Billentyű |
|---|---|
| mozgás | A / D vagy ← / → |
| fúrás lefelé | S vagy ↓ (tartsd) |
| fúrás oldalra | falnak tolva tartsd az irányt |
| emelés | W, ↑ vagy Space |
| bázis (a padon) | E |
| térkép | M / Tab |
| fényszóró | L |
| vészjeladó | B tartása 2 mp |
| szünet | Esc |

## Állapot

Fejlesztés alatt: az M0 és M1 kész, az M2 (vizuális vertical slice) folyamatban. Csak az MK-I Rustler játszható.
